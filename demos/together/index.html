Together

They write what a Button is. Decree refuses any Button a checkout used that they did not permit.

Nathan — Specs 2

Authors Harbor Button in YAML: primary | secondary, sizes, illegal secondary + lg, Ghost deprecated. Anatomy and default styles stay in the spec.

demos/together/nathan/specs.yaml

TJ — DS Contracts

Authors the same Button as a contract: props, Figma/code bindings, semantics.element: button. Anatomy and bindings stay in the contract file.

demos/together/tj/contracts/button.contract.json

Decree — judge slice

Compiles names, props, combos, tokens, deprecations, native <button>, and restyle refusal. Does not become a spec language or a code generator.

decree prepare --from-specs · --from-ds-contracts

The situation

  1. Harbor is a fictional third-party system (not Corvy, not SD33DS).
  2. A clean checkout uses variant="primary" and size="md".
  3. A dirty checkout uses ghost, a forbidden combo, style=, deprecated Ghost, an invented MagicButton, and a raw <button>.
  4. Decree verify passes the clean app and fails the dirty one.
