Decree · case study

Pulse product ecosystem

A small model of how teams actually ship: a design-system package, then two product apps — one built with the system, one rebuilt from a screenshot by AI. Same contract. Different outcomes.

This page is static — open index.html in a browser (no server). The two product apps below need Vite.

Start the demo apps

From demos/pulse-reports/ (this folder — not the Decree repo root). First time run npm install here; it wires the package + both apps. 

cd demos/pulse-reports
npm install

# Terminal 1 — Pulse Reports (uses @pulse/ui)
npm run dev
# opens http://127.0.0.1:5180

# Terminal 2 — Pulse Reports AI (screenshot rebuild)
npm run dev:ai
# opens http://127.0.0.1:5181

Design system package packages/pulse-ui is a dependency — no separate server. After the apps are up, use the Open links below.

The story

  1. Default shadcn — ui.shadcn.com/themes (stock kitchen sink).
  2. @pulse/ui — design system package for this demo (components, tokens, decree.contract.json).
  3. Pulse Reports — consumes @pulse/ui. Decree verify: pass.
  4. Screenshot — evidence of Pulse Reports (in evidence/).
  5. Pulse Reports AI — agent rebuild from that screenshot. Decree verify with the same contract: fail.

Trial run (Decree)

From the Decree repo root. Output is terminal findings. 

# Design system — regenerate contract
node bin/decree.js prepare demos/pulse-reports/packages/pulse-ui

# Product app inherits the rulebook
node bin/decree.js use demos/pulse-reports/packages/pulse-ui --force \
  --out demos/pulse-reports/apps/pulse-reports/decree.contract.json
# (ensure scan.profile app + excludes on the app contract — see README)

node bin/decree.js verify demos/pulse-reports/apps/pulse-reports
# expect: ok

# Same rulebook on the AI app
cp demos/pulse-reports/apps/pulse-reports/decree.contract.json \
   demos/pulse-reports/apps/pulse-reports-ai/decree.contract.json
node bin/decree.js verify demos/pulse-reports/apps/pulse-reports-ai
# expect: fail
