# Decree code audit — 2026-08-04

Scope: `src/`, `bin/`, `tests/`, `scripts/run-external-trials.mjs`  
Context: post import-aware allowlisting + contract profiles on `main`.

## Verdict

Solid verify-first POC architecture. Highest risks are **policy false negatives** (`FRAMEWORK_COMPONENTS` silent allow) and **path containment** on init/verify inputs — not missing features.

## Strengths

- Stable `DECREE_*` codes; clean/dirty fixtures; shared `scanSource` for CI + MCP
- Import aliases + `scan.profile: "app"` match real third-party noise
- Init covers PascalCase / kebab `ui/` / nested package roots
- CLI uses argv arrays (no shell injection in trials helpers)
