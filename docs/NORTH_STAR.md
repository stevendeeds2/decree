# North Star

They write what a Button **is**. Decree refuses any Button an app or agent **used that the contract did not permit** — name, prop, value, token, then restyle.

## Positioning

Decree is the enforcement / refuse layer for design systems: contracts, CI verify, and agent MCP allowlists.

If it's not in the system, it doesn't ship.

Decree is complementary to Nathan Curtis (Specs 2) and TJ Pitre (Context-Based Design Systems, Figma Console MCP, Southleft DS Contracts). They author and project intent. Decree judges consumer apps and agents.

The judge slice is not spec language. Do not grow an anatomy/layout schema, a Figma extract, or a code generator.

Stay the judge. They stay the authors. The join later is adapters that compile a judge slice from Specs / DS Contracts.

## What Decree will become

- A contract that names permitted components, then (when configured) permitted props, values, combinations, tokens, and restyle refusal.
- CI verify that refuses usage the contract did not permit.
- Agent MCP allowlists that expose only that same permitted surface.
- Adapters that compile a judge slice from Specs 2 or DS Contracts after component APIs exist.

## What Decree will not become

- Specs 2, DS Contracts, or any authoring / projection product.
- An anatomy or layout schema.
- A Figma extract or code generator.
- A restyle engine.

Do not dogfood Decree on Corvy, stevendeeds.com, or `@stevendeeds/sd33ds` production.
